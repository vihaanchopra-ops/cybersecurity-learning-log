# Networking Basics

## IP Addresses
An IP address identifies a device on a network
and allows it to communicate with other devices.

## DHCP
Dynamic Host Configuration Protocol (DHCP)
automatically assigns IP configuration to devices.

## DNS
Domain Name System (DNS) translates domain names
into IP addresses.

## TCP and UDP
TCP provides reliable, connection-oriented
communication.

UDP provides faster, connectionless communication
without guaranteeing delivery.
